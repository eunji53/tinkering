# 논문 요약 형식

Claude Code로 정리할 때와, 나중에 API 스크립트(`src/generate_summary.py`, 예정)로 정리할 때 모두 이 형식을 쓴다.
형식을 바꾸려면 이 파일만 고친다.

## 입력

`output/<논문>_extract_<날짜>/` 폴더

- `full_text.md`: 정리된 본문 (그림·표·수식 자리 표시, 문장 속 수식은 `$...$` LaTeX)
- `extraction_report.md`: 그림·표·수식 목록과 캡션
- `figures/`, `tables/`, `equations/`: 이미지

## 출력

1. 로컬 사본: `output/<논문>_summary_<날짜>.md`
2. Notion "논문 리뷰" 데이터베이스에 한 행

## Notion 데이터베이스 속성

| 속성 | 내용 |
|---|---|
| 제목 | 논문 제목 (영문 원제) |
| 링크 | arXiv 등 논문 주소 |
| 연도 | 공개 연도 |
| 기관 | 저자 소속 |
| 태그 | 주제 태그 (없으면 새로 추가) |
| 3줄 요약 | 아래 3줄 요약을 각각 한 줄로 줄여 줄바꿈으로 구분 (🚀 / 💡 / 📈 각 한 줄) |
| 정리일 | 정리한 날짜 |
| 상태 | `읽을 예정` (처음 만들 때) |

## 페이지 본문 (한국어)

맨 위에 저자·소속, 공개 시기, 논문·코드 링크를 목록으로 적은 뒤 아래 순서로 쓴다.

1. **3줄 요약**: 🚀 무엇을 했나 / 💡 핵심 방법 / 📈 주요 결과. 각 1~2문장.
2. **용어 정리**: 논문을 읽는 데 필요한 핵심 용어 10~16개를 `| 용어 | 설명 |` 표로. 처음 보는 사람도 이해하게 쉬운 말로.
3. **상세 요약**: `배경과 문제` / `방법` / `실험 결과` / `한계` 소제목. 수치는 본문·표에서 그대로 가져오고 근거 표·그림 번호를 괄호로 단다.
4. **주요 그림·표**: 핵심 3~4개를 이미지로 넣고 캡션에 한 문장 설명.
5. **주요 수식**: 번호 있는 핵심 수식을 이미지를 보고 LaTeX로 옮겨 `$$` 블록으로. 각 수식 앞에 한 줄 설명, 끝에 원래 번호 `\quad (n)`.
6. **내 메모**: 빈칸.

## 지킬 것

- 논문에 없는 내용을 지어내지 않는다. 수치·주장은 추출 텍스트와 대조한다.
- 추출 텍스트가 깨진 수식은 `equations/` 이미지를 보고 옮긴다.
- 원본 파일(`input/`, `*_extract_*`)은 수정하지 않는다.
