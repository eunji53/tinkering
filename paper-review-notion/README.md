# paper-review-notion

논문 PDF를 넣으면 텍스트/이미지/표를 추출하고, 이를 바탕으로 리뷰 초안을 만들어
Notion에 정리하는 자동화 파이프라인. (`papers-digest`와 달리 논문 한 편을 깊이 있게
리뷰하는 용도)

## 폴더 구조

```
paper-review-notion/
  input/          # 리뷰할 논문 PDF 원본을 넣는 곳
  src/            # 추출·생성 스크립트
  output/         # 추출된 텍스트/이미지, 생성된 리뷰 결과물
  tests/          # 테스트용 스크립트
  docs/           # 설계 문서
```

## 진행 단계

1. **PDF 추출 테스트** (진행 중): `input/`의 논문 PDF에서 텍스트·이미지·표를 추출해
   `output/`에 저장하고 품질을 확인한다. 아직 Notion에는 아무것도 쓰지 않는다.
2. 리뷰 초안 생성: 추출한 내용을 바탕으로 구조화된 리뷰 마크다운 작성.
3. Notion 발행: Notion API로 실제 페이지 생성 (사용자 승인 후 진행).
