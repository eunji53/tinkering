# 작업 기록 — 2026-07-30

## 오늘 한 일

### 1단계: PDF → 텍스트/그림/표/수식 추출 파이프라인 구축 (`src/extract_pdf.py`)

- 논문 PDF에서 본문 텍스트, 그림(Figure), 표(Table), 번호 매겨진 수식을 각각 이미지/텍스트로 추출.
- 그림/표는 "Figure N", "Table N" 캡션 텍스트를 앵커로 찾아 그 주변(텍스트+벡터 드로잉+임베딩 이미지)을
  페이지 렌더링 방식으로 통째로 크롭하는 방식 채택. `pdfplumber` 선(line) 기반 표 감지나 임베딩 raster
  이미지 추출만으로는 벡터로 그려진 그림이나 선이 거의 없는 booktabs 스타일 표를 놓쳐서 채택하지 않음.
- 수식은 "(1)", "(2)" 같은 수식 번호(소괄호+1~3자리 숫자로 끝나는 패턴)를 앵커로 캡처.

### 테스트 및 발견/수정한 버그

**LIGHTRAG.pdf로 검증**
- 첫 다운로드 파일이 텍스트 레이어 없이 벡터 윤곽선으로 변환된 버전이라 추출이 전혀 안 됨 → 원본 arXiv PDF로 재다운로드
- 표 오탐지(그림 안 장식 텍스트 박스를 표로 인식), Figure 1(벡터 그림)이 통째로 누락되는 문제 → 캡션 기반 크롭 방식으로 해결
- "M ="처럼 짧은 수식 조각이 섹션 제목(헤딩)으로 오인되어 스캔이 조기 종료되는 버그 수정
- Table 3 내부 서술형 텍스트(사례 비교 답변)가 본문 문단으로 오인되어 스캔이 멈추는 문제 → 표 구분선 안쪽이면 문단처럼 보여도 안 멈추게 처리
- Figure 2처럼 캡션이 내용 "위"에 있는 예외 케이스 → 캡션 위/아래 양쪽 다 스캔해서 실제 내용 있는 쪽 채택
- 결과: 그림 7개, 표 5개, 수식 2개 모두 정확히 추출 확인 (직접 이미지로 검증)

**Boogu-Image-0.1.pdf(70페이지, 훨씬 복잡한 논문)로 일반화 검증**
- 캡션 정규식을 "Figure/Fig, Table/Tab 축약형 + 대소문자 무관 + 번호 뒤 마침표/콜론 유무 무관"하도록 일반화
- 차트가 있는 그림들이 위쪽이 잘리는 문제 → y축 눈금 숫자("0" 등)가 페이지 번호로 오인식되어 스캔이 조기 종료되는 버그가 원인. "페이지 여백 근처에 있을 때만 페이지 번호로 인정"하도록 수정
- 벡터 드로잉이 고정 여백(margin) 제한 때문에 큰 차트를 다 못 담는 문제 → "서로 맞닿은 드로잉을 계속 이어붙이는" flood-fill 방식으로 교체
- 흰색 배경용 장식 사각형이 크롭 범위를 불필요하게 넓히는 문제 → 눈에 안 보이는 흰색 채우기 도형 필터링
- 본문 문장이 "Table 4 presents..."처럼 번호로 시작해 실제 캡션과 같은 파일명으로 충돌(덮어쓰기 위험)하는 문제 → 같은 번호 후보가 여럿이면 실제 이미지/드로잉이 더 많이 포함된 쪽을 선택하도록 처리
- 결과: 그림 37개, 표 11개, 수식 12개 추출 (수식 중 2개는 오탐으로 확인 — 코드 블록, 차트 축 눈금)
