# rag-experiments 다음 작업 정리

## 1. product-recommendation v3 — 다음 버전 계획

`product-recommendation/README.md`의 "13. 다음 단계: v3 계획" 섹션이 최신 로드맵(v0/v1/v2 노트북 끝의 "다음 단계" 셀도 이 README를 참고하도록 이미 수정해둠).

핵심 방향: **현재 상품 검색을 추천의 중심에 두고, 거래 Profile은 순위 보정 신호로만 활용.**

v3 주요 과제 (README에 이미 정리됨):
- 구매 상황 중심 Profile 재설계 (상품분류를 그룹 키에서 제거)
- 현재 상품의 판매상태·가격·MOQ 필터
- Profile별 상품분류 비율 기반 재정렬
- 관련도 임계값 적용
- 최근 거래 가중치
- 후보 상품 ID 검증
- 평가셋과 Hit@5 도입

> 참고: 예전에 논의했던 "임베딩 모델 비교(TF-IDF vs bge-m3 vs SBERT)"는 v2 문제와 직결되지 않는 별개 실험이라 v3에서 제외하기로 함. 하고 싶으면 나중에 별도 실험(v4 또는 부록)으로.
