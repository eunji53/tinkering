### 1. RAG 학습 방향 설정

**문제 인식**  
RAG-Anything 코드를 학습했지만 파이프라인 수준에서만 이해됨.  
RAG-Anything은 LightRAG(지식그래프 + 벡터 하이브리드) 위에 멀티모달을 얹은 고급 프레임워크라 입문용으로 부적합.

**결론: 아래 순서로 학습**

```
① 나이브 RAG 직접 구현 (지금 단계)
   문서 → 청킹 → 임베딩 → 벡터 검색 → LLM 답변

② 검색 품질 개선
   BM25(키워드) + 임베딩(의미) 하이브리드 검색

③ LightRAG 코드 읽기
   지식 그래프 + 벡터 검색 결합 방식 이해

④ RAG-Anything 재독
   멀티모달(이미지/표/수식) 처리 레이어 이해
```

### 4. Ollama LLM 연동

```python
OLLAMA_BASE_URL = 'http://localhost:11434'

```

- Ollama 실행 중이면 API 키 없이 자동 사용
- 미실행 시 Anthropic → OpenRouter 순으로 fallback

### 5. 모델 비교 실험 (섹션 6-2, 6-3)

**6-2: Ollama 모델별 임베딩 비교**  
설치된 6개 모델 각각으로 FAQ 임베딩 생성 후 동일 질문으로 검색 결과 비교.

```
사용 가능 모델: bge-m3:latest, gemma3:4b, gemma2:9b, gemma3:12b, qwen2.5:7b, qwen2.5:3b
API: POST http://localhost:11434/api/embed
```

- `bge-m3:latest`는 임베딩 전용 모델 → 품질 기준선
- LLM 모델들은 임베딩 추출 가능하나 품질 차이 있음

| `snunlp/KR-SBERT-V40K-klueNLI-augSTS` | BERT | KLUE-NLI + augSTS |

두 모델 모두 768차원, 첫 실행 후 `.npy`로 캐시 저장됨.
